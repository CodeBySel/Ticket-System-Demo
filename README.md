# Ticket-System-Demo

System for handling reservations and selling tickets in the cinema.

This project is a Demo full-stack web application designed to manage cinema ticket sales and seat reservations efficiently. It uses a **Layered Architecture (MVC)** to ensure clean separation between the user interface, business logic, and database management.

---

## ✨ Features

* 🎬 **Movie Catalog**: Browse available movies with posters.
* 💺 **Interactive Seat Map**: Real-time seat selection (5 rows × 8 seats).
* 🎫 **Dynamic Pricing**: Automatic total price calculation.
* 👤 **Customer Registration**: Simple form to collect customer info per booking.
* 📄 **PDF Export**: Download your ticket confirmation as a PDF file.
* 🔄 **Full Navigation**: Easy forward/backward flow through the booking process.

## 🛠️ Tech Stack

| Tier | Technology | Usage |
| :--- | :--- | :--- |
| **Backend** | Java 17, Spring Boot | RESTful API & Business Logic |
| **Frontend** | React 18, Vite | Interactive UI & State Management |
| **Database** | H2 (In-memory) / PostgreSQL | Data persistence |
| **Security** | Spring Security | Basic security & CORS config |
